D0 Native Recovery

D0 Native Recovery is a private, personal-use backup utility operated by the owner of this site. It creates ordinary offline recovery copies of the owner's Google Workspace files, such as Google Docs and Google Sheets.

Google Drive access

The application requests read-only Google Drive access. It uses that access to locate and export the owner's Google Workspace files into standard file formats for disaster recovery.

D0 Native Recovery does not create, edit, move, rename, or delete files in Google Drive. It is not offered as a public service and is intended for use only by its owner.

Data handling

Exported recovery copies and OAuth credentials are stored only on systems controlled by the user. Google user data is not sold, used for advertising, or shared with third parties.
