Privacy Policy — D0 Native Recovery

Effective date: September 20, 2026

Purpose

D0 Native Recovery is a private personal-use utility that creates local disaster-recovery copies of Google Workspace files owned or accessible by the authorized user.

Google user data accessed

The application uses Google Drive read-only authorization to read file metadata and file contents required to locate and export Google Workspace files such as Google Docs and Google Sheets.

How data is used

Google user data is used solely to create local backup and recovery copies for the authorized user. The application does not modify Google Drive contents.

Storage

OAuth credentials and exported recovery files are stored only on systems controlled by the user. The application does not operate a third-party data storage service.

Sharing and advertising

Google user data is not sold, rented, used for advertising, or shared with third parties.

Retention and deletion

The user controls the retention and deletion of locally exported recovery files and may revoke the application's Google account access at any time through Google Account security settings.
