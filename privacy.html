Keelaryn Privacy Policy

Effective: 19 September 2026

Purpose

Keelaryn is a personal knowledge-management and automation system. This policy describes how Keelaryn handles Google user data when the user authorizes Google Drive access.

Google account authorization

Keelaryn accesses Google Drive only after the user explicitly authorizes access through Google's OAuth authorization process. The requested Google Drive permission allows Keelaryn to see, create, edit, move, and delete Drive files as required by the user's Keelaryn workflow.

Google user data accessed

Keelaryn may access Google Drive file and folder content, names, identifiers, metadata, hierarchy, and other Drive information needed to identify and operate the user's Drive-backed Keelaryn repository.

How Google user data is used

Google Drive data is used only to provide Keelaryn functionality and to perform operations initiated or configured by the user. Depending on the requested operation, Keelaryn may read, create, update, move, reconcile, or delete files and folders.

Storage and retention

Persistent Keelaryn content stored in Google Drive remains in the user's Google Drive until it is changed or deleted by the user or by a Keelaryn operation the user has initiated or configured.

Keelaryn may temporarily process or retain working data, logs, and operational metadata on systems controlled by the operator when necessary to perform or validate Keelaryn operations. Such data is retained only for operational, troubleshooting, rollback, or provenance needs and is removed or rotated when it is no longer required for those purposes.

OAuth credentials may be retained on operator-controlled systems so that authorized Keelaryn operations can continue. The user may revoke Google OAuth access through their Google Account permissions, and credentials can also be replaced or deleted from the Keelaryn runtime.

Sharing and disclosure

Keelaryn does not sell Google user data and does not disclose Google user data to advertisers, data brokers, or unrelated third parties.

Google user data may be processed by infrastructure or service providers explicitly configured by the operator only when necessary to provide requested Keelaryn functionality. Such processing is limited to that operational purpose.

Security

Keelaryn uses HTTPS for communications with Google APIs. OAuth credentials and operational data stored by the Keelaryn runtime are kept on operator-controlled systems and protected using access controls appropriate to those systems.

Advertising, sale, and AI/ML training

Keelaryn does not use Google user data for advertising, advertising profiles, sale to third parties, credit or lending decisions, or unrelated commercial purposes.

Keelaryn does not use Google Workspace API data to develop, improve, or train generalized or non-personalized artificial intelligence or machine-learning models.

Deletion and revocation

The user can delete Drive-backed Keelaryn files directly in Google Drive or through authorized Keelaryn operations. The user can also revoke Keelaryn's Google account access at any time through Google Account permissions. Revocation prevents future API access using the revoked authorization.

Public website

This public website does not require Google Drive access and does not display the contents of the user's Keelaryn repository.

Personal use

Keelaryn is currently operated as a personal-use application.

Google API Services User Data Policy

Keelaryn's use of information received from Google APIs is intended to comply with the Google API Services User Data Policy, including applicable Limited Use requirements.
