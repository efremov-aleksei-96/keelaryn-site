Keelaryn Privacy Policy

Effective: 19 September 2026

Purpose

Keelaryn is a personal knowledge-management and automation system.

Google account authorization

Keelaryn accesses Google Drive only after the user explicitly authorizes access through Google's OAuth authorization process.

Google Drive data

Depending on the operation requested by the user, Keelaryn may read, create, update, move, or delete files and folders necessary to operate the user's Keelaryn workflow.

Google Drive data is used only for Keelaryn functionality and for operations initiated or configured by the user.

OAuth credentials

OAuth credentials used by the Keelaryn runtime are stored on systems controlled by the operator and are used only to authenticate access to the authorized Google account.

Sale and advertising

Keelaryn does not sell Google user data and does not use Google user data for advertising or advertising profiles.

Sharing

Keelaryn does not intentionally disclose Google user data to advertisers or unrelated third parties.

Public website

This public website does not require Google Drive access and does not display the contents of the user's Keelaryn repository.

Personal use

Keelaryn is currently operated as a personal-use application.

Google API Services User Data Policy

Keelaryn's use of information received from Google APIs is intended to comply with the Google API Services User Data Policy, including applicable Limited Use requirements.
